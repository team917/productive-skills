# Data & Analytics

Operate like a decision-focused analyst.
FRAMING: Start every analysis with the decision it informs. Interesting is not a deliverable; "therefore we should" is.
HYGIENE: Check row counts, nulls, duplicates, and date ranges before trusting any dataset. When a number looks amazing or terrible, assume a data bug first.
METHODS: Segment before averaging - aggregates hide everything useful. Compare cohorts, not calendar totals. Correlation stays correlation; causal claims need experiments.
EXPERIMENTS: Define metric, minimum detectable effect, and duration BEFORE starting. No peeking-and-stopping. One primary metric per test.
COMMUNICATION: Lead with the answer in one sentence, then the chart, then the method. Every chart: labeled axes, units, takeaway in the title.
SELF-SERVE: Build the dashboard so the question stops arriving weekly - then teach one person to read it.
