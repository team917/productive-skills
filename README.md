# Productive skills

Role playbooks for agents running on [Productive](https://productive.team). Each skill is a
short operating manual an agent follows when it is given that job: how to prospect, write,
review, analyze, support, ship.

Install as a skill source in the Productive console (Tools > Skill sources > Add), or point
any agent at this repo: `team917/productive-skills`, ref `main`, directory `skills`.

| Skill | Role | Stance |
|---|---|---|
| `ai-contract-review` | AI Contract Review | Operate like a paralegal/co-pilot, not a lawyer - flag risk and gaps, never issue binding legal advice, and say so up front on every task. |
| `backend-engineering` | Backend Engineering | Operate like a senior backend engineer who owns correctness AND uptime. |
| `cloud-architecture` | Cloud Architecture | Operate like a solutions architect: design for the failure modes, not just the happy path. |
| `cold-outreach` | Cold Outreach | Operate like an SDR who treats every sequence as a measured experiment, not a guess. |
| `copywriting` | Copywriting | Operate like a conversion copywriter. |
| `customer-success` | Customer Success | Operate like a retention-first CS manager. |
| `data-analysis` | Data & Analytics | Operate like a decision-focused analyst. |
| `data-engineering` | Data Engineering | Operate like a data engineer who treats pipelines as production software. |
| `database-administration` | Database Administration | Operate like a DBA: the data is the one thing you can't rebuild from source. |
| `devops-sre` | DevOps & Site Reliability | Operate like an SRE: the system's reliability is a feature you own, not an accident. |
| `engineering-leadership` | Engineering Leadership | Operate like a CTO/VP Engineering: the business's technical bets are your responsibility. |
| `exec-assistant` | Executive Assistant | Operate like a world-class EA. |
| `financial-analysis` | Finance & Analysis | Operate like a sharp fractional CFO/analyst. |
| `financial-modeling` | Financial Modeling | Operate like an FP&A analyst who ties every model out to zero before presenting it. |
| `interaction-design` | Interaction Design | Operate like an interaction designer who times feedback to human perception, not to what's convenient to build. |
| `linkedin-management` | LinkedIn Management | Operate like a LinkedIn creator-ops lead who treats every post as an experiment, not a diary entry. |
| `marketing-playbook` | Marketing Playbook | Operate like a seasoned SaaS/SMB marketer. |
| `ml-ai-engineering` | ML / AI Engineering | Operate like an ML engineer who ships models into production, not notebooks. |
| `mobile-development` | Mobile Development | Operate like a senior mobile engineer shipping to real app stores with real users. |
| `ops-sops` | Operations & SOPs | Operate like a systems-obsessed COO. |
| `product-analytics` | Product Analytics | Operate like an analytics engineer who treats a metric as unverified until its SQL is written. |
| `product-management` | Product Management | Operate like an outcome-driven PM. |
| `qa-testing` | QA & Testing | Operate like a QA engineer whose job is to find the bug before the user does. |
| `recruiting-hr` | Recruiting & HR | Operate like a pragmatic head of talent. |
| `sales-outbound` | Outbound Sales | Operate like a disciplined SDR/closer. |
| `security-engineering` | Security Engineering | Operate like a security engineer: assume attackers and mistakes both happen. |
| `seo-content` | SEO & Content | Operate like a technical + content SEO lead. |
| `social-media` | Social Media | Operate like a growth-minded social manager. |
| `strategy-frameworks` | Strategy Frameworks | Operate like a chief of staff who names the real challenge before proposing a plan. |
| `support-triage` | Support Triage | Operate like a support lead who classifies before responding, never reacts to tone alone. |
| `talent-sourcing` | Talent Sourcing | Operate like a recruiter who scores candidates against evidence, not gut feel. |
| `web-development` | Web Development | Operate like a senior web engineer who ships production code, not demos. |

Format follows the [Agent Skills](https://skills.sh) layout: one directory per skill with a
`SKILL.md` carrying `name` and `description` frontmatter and the playbook as the body.
